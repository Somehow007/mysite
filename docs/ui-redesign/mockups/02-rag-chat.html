这个站点的搜索是怎么实现的？

这个站点的搜索基于可插拔的搜索架构实现：文章发布或更新后会同步写入 Elasticsearch 索引1；查询时先走分词检索，再叠加向量召回做混合排序，兼顾关键词精确匹配与语义相关度2。

部署上通过 docker-compose 一键启动 ES 与后端服务，核心配置如下：

application.ymlyaml
search:
  engine: elasticsearch  # 可切换 mysql / none
  elasticsearch:
    uris: http://localhost:9200
    index: mysite_articles

那向量检索用的什么模型？

向量检索使用的是 bge-small-zh-v1.5 中文嵌入模型：文章入库时先按 512 token 切分片段并计算向量，存入 ES 的 dense_vector 字段；提问时把问题同样编码为向量，通过余弦相似度召回 Top-K 片段交给大模型生成回答
