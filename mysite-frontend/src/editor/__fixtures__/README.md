# Round-trip 测试用例集

用于编辑器重构（见 `docs/editor-redesign-plan.md` §6 第 1 阶段）的兼容性验证。

## 用途

`roundtrip-article.md` 覆盖了 `src/composables/useMarkdown.ts` 渲染管线支持的全部
Markdown 方言：标题、行内格式、三类列表（含嵌套与任务列表）、普通引用、Callout
（多种类型 / 无标题 / 多行正文）、代码块（多语言 / 无语言）、行内与块级数学公式、
表格、图片、分割线、行内 HTML（`<u>`）、混合嵌套场景、中英混排。

## 验收方式

新编辑器（Milkdown Crepe）实施的每个阶段完成后：

1. 用编辑器打开本文件内容；
2. 不做任何修改，直接触发序列化（等价于保存）；
3. 对比序列化输出与原文：允许空白、列表标记（`-`/`*`）、强调标记（`**`/`__`）等
   等价差异，**不允许**语义差异（语法丢失、Callout 类型被吞、公式定界符改变、
   HTML 被转义等）；
4. 将序列化结果交给 `useMarkdown.ts` 渲染，与原文渲染结果比对，DOM 结构应一致。

发现差异即视为 round-trip 缺陷，须在进入下一阶段前修复。
